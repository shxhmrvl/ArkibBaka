# Arkib:Baka (Advanced Digital Memorial Archive)

An editorial-grade public digital museum for the Baka community spanning **2018–2026**.

## Key Upgrades
- **Synthesized Ambient Soundscape**: Live harmonic pad & vinyl hiss engine using the Web Audio API with animated audio bars.
- **Global Command Palette (`Cmd+K` / `Ctrl+K`)**: Rapid navigation and search across years, people, eras, and saved fragments.
- **Interactive Memorial Vault & Lightbox**: Full story viewer with reaction counters (❤️, 🔥, 🎮) and personal bookmarking drawer.
- **Nine-Year Interactive Timeline**: Detailed yearly chapter exploration with milestone statistics and member metrics.
- **Hall of Fame (`/people`)**: Recognition cards with badges and memorable quotes.
- **Era Epochs (`/eras`)**: 4 major community eras detailing the progression from late-night CS:GO lobbies to quarantine sanctuaries and permanent digital preservation.
- **Community Guestbook 2.0**: Themed note submission with local persistence and one-click JSON export.
